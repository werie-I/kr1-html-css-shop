## CSS-архитектура

Основные переменные проекта находятся в `:root`.

Используются группы переменных:

- цвета;
- отступы;
- скругления;
- размеры контейнера.

Для использования переменных применяется функция `var()`.

CSS организован по смысловым блокам:

1. Переменные проекта.
2. Базовые стили.
3. Шапка и навигация.
4. Главная страница и основные разделы.
5. Сетка товаров.
6. Карточки товаров.
7. Каталог и фильтры.
8. Кнопки.
9. Дополнительный информационный блок.
10. Модальное окно.
11. Форма заказа.
12. Хлебные крошки.
13. Якорные ссылки.

## Методология БЭМ

БЭМ используется для единообразного именования CSS-классов.

- **Блок** — самостоятельный компонент, например `product-card`.
- **Элемент** — часть блока, например `product-card__title`.
- **Модификатор** — вариант внешнего вида или состояния, например `button--primary`.

Примеры классов проекта:

- `site-nav` — блок навигации;
- `site-nav__link` — ссылка внутри навигации;
- `product-card` — карточка товара;
- `product-card__button` — кнопка карточки товара;
- `product-card--featured` — модификатор карточки;
- `button--primary` — модификатор кнопки.
