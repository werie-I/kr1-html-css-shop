# Чайный клуб

Учебный многостраничный сайт интернет-магазина чая и пространства чайной культуры.
Проект демонстрирует навыки, полученные на практических занятиях № 1–7 по дисциплине
«Фронтенд и бэкенд разработка».

## Страницы проекта

- `index.html` — главная страница.
- `catalog.html` — каталог сортов чая.
- `product.html` — карточка товара.
- `cart.html` — корзина.
- `order.html` — оформление заказа (демонстрационная форма).
- `ceremony.html` — описание чайных церемоний.
- `booking.html` — отдельная страница бронирования церемонии (демонстрационная форма).
- `tea-guide.html` — интерактивный подбор чая.
- `tea-history.html` — история и культура чая.
- `favorites.html` — избранные товары.
- `reviews.html` — отзывы (демонстрационные данные и локальное добавление отзыва).
- `contacts.html` — контактная информация и форма обратной связи.

## Использованные навыки практических занятий № 1–7

### Практическое занятие № 1 — Git, GitHub, Pull Request и GitHub Pages
- проект хранится в Git-репозитории;
- предусмотрена работа с ветками, коммитами и Pull Request;
- проект может быть опубликован через GitHub Pages.

### Практическое занятие № 2 — HTML-каркас и базовое CSS
- используется структура HTML5;
- применяются семантические элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- стили подключаются отдельными CSS-файлами.

### Практическое занятие № 3 — форма, модальное окно и валидация
- на `booking.html` размещена отдельная форма бронирования;
- используются `form`, `label`, `input`, `select`, `textarea`, `button`;
- применяются `required`, `minlength`, `maxlength`, `pattern`, `type="email"`, `type="tel"`, `type="date"`;
- результат демонстрируется через HTML-элемент `dialog` и JavaScript;
- браузерная клиентская валидация выполняется до показа подтверждения.

### Практическое занятие № 4 — CSS-переменные, архитектура и состояния
- цвета, отступы и скругления вынесены в CSS custom properties в `:root`;
- переменные используются через `var()`;
- предусмотрены состояния `:hover`, `:focus`, `:focus-visible`, `:disabled`;
- добавлены адаптивные правила через media queries.

### Практическое занятие № 5 — многостраничный сайт и навигация
- сайт разделён на самостоятельные HTML-страницы;
- используется общая навигация, подключаемая из `js/components.js`;
- применяются внутренние ссылки и переходы между страницами;
- для страниц заданы уникальные `title` и `meta description` там, где они предусмотрены.

### Практическое занятие № 6 — Flexbox и Grid
- Flexbox используется для общей шапки и навигации;
- CSS Grid применяется для сеток карточек, каталога и формы бронирования;
- сетки адаптируются под ширину экрана.

### Практическое занятие № 7 — методология БЭМ
- общие повторно используемые компоненты оформлены по БЭМ: `site-header__link`, `site-header__menu-button`, `booking-form__field`, `booking-form__control`;
- используются модификаторы, например `site-header__link--active` и `site-header__nav--open`;
- общие компоненты вынесены в отдельный CSS-файл `css/site-components.css`.

## Интерактивные элементы интерфейса

- На главной странице добавлен авторский SVG-элемент: по нажатию кнопки анимируется струя чая, наполнение чашки и лёгкий пар. Иллюстрация встроена в HTML и не требует отдельного изображения.
- В шапке сайта навигация сгруппирована: второстепенные информационные страницы находятся в раскрывающемся меню «О клубе», а бронирование выделено отдельной контрастной кнопкой. На небольших экранах навигация сворачивается в мобильное меню.
- На главной странице размещён интерактивный таймер заваривания. Для сенчи, чёрного, белого чая и улуна заданы демонстрационные рекомендации по времени и температуре; таймер можно запускать, ставить на паузу и сбрасывать. Рекомендации могут отличаться в зависимости от сорта, количества листа и личных предпочтений.
- Для пользователей, предпочитающих уменьшенное движение, предусмотрена CSS-настройка `prefers-reduced-motion`.
