## CSS-архитектура

Основные переменные проекта находятся в `:root`.

Используются группы переменных:

- цвета;
- отступы;
- скругления;
- размеры контейнера.

Для использования переменных применяется функция `var()`.

CSS организован по смысловым блокам:

1. Переменные проекта.
2. Базовые стили.
3. Шапка и навигация.
4. Hero-блок.
5. Основные разделы.
6. Карточки товаров.
7. Кнопки.
8. Дополнительный информационный блок.
9. Модальное окно.
10. Форма.
11. Успешное сообщение.
