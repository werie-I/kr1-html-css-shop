## Методология БЭМ

БЭМ используется для единообразного именования CSS-классов.

- **Блок** — самостоятельный компонент, например `product-card`.
- **Элемент** — часть блока, например `product-card__title`.
- **Модификатор** — вариант внешнего вида или состояния, например `button--primary`.

Примеры классов проекта:

- `site-nav` — блок навигации;
- `site-nav__link` — ссылка внутри навигации;
- `product-card` — карточка товара;
- `product-card__button` — кнопка карточки товара;
- `product-card--featured` — модификатор карточки;
- `product-card--new` — вариант карточки для новинки;
- `button--primary` — модификатор кнопки;
- `faq__item` — элемент блока FAQ.
